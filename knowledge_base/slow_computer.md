# Slow Computer

## Symptoms
- Applications take a long time to open.
- The computer feels sluggish.
- Switching between applications is slow.

## Troubleshooting
1. Restart the computer.
2. Close unnecessary applications.
3. Open Task Manager and check CPU, memory, and disk usage.
4. Disable unnecessary startup applications.
5. Make sure sufficient disk space is available.
6. Install approved operating-system updates.
7. Run an approved security scan.

## Escalation
Escalate when the system is consistently slow after basic maintenance or if hardware diagnostics report errors.
