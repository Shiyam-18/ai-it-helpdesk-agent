# Slow Network

## Symptoms
- Websites load slowly.
- Downloads are unusually slow.
- Multiple applications have network delays.

## Troubleshooting
1. Test whether the slowdown affects multiple devices.
2. Restart the router if appropriate.
3. Pause large downloads or cloud synchronisation.
4. Move closer to the Wi-Fi access point if using wireless.
5. Check whether the issue is limited to one application or website.
6. Contact the network administrator when the problem affects multiple users.

## Escalation
Escalate widespread or persistent network performance issues.
