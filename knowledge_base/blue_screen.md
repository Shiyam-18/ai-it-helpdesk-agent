# Windows Blue Screen

## Symptoms
- System shows a blue-screen error and restarts.
- Crashes occur repeatedly.

## Troubleshooting
1. Record the stop code if visible.
2. Restart the computer.
3. Disconnect recently added peripherals if safe to do so.
4. Install approved Windows and driver updates.
5. Check whether the issue started after a recent driver or software change.
6. Run built-in Windows diagnostics where appropriate.
7. Back up important files if the system remains unstable.

## Escalation
Repeated blue screens should be escalated, especially when hardware failure is suspected.
