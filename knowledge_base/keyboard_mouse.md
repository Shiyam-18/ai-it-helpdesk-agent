# Keyboard or Mouse Not Working

## Troubleshooting
1. Check the physical connection or Bluetooth status.
2. Try another USB port if applicable.
3. Replace or recharge batteries for wireless devices.
4. Restart the computer.
5. Test the device on another computer when possible.
6. Check whether the keyboard or mouse appears correctly in the operating system.

## Escalation
Escalate when the device fails across systems or physical damage is present.
