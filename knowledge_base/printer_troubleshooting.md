# Printer Not Printing

## Symptoms
- Print jobs stay in queue.
- Printer appears offline.
- Documents do not come out.

## Troubleshooting
1. Confirm the printer has power.
2. Check the USB or network connection.
3. Make sure the correct printer is selected.
4. Cancel stuck jobs from the print queue.
5. Restart the printer and computer.
6. Check whether the printer shows an error on its display.
7. If it is a network printer, verify the printer and computer are on the same network.

## Escalation
Escalate when hardware errors persist or the printer remains unavailable after standard checks.
