# Software Installation Failure

## Symptoms
- Installer fails.
- Installation stops unexpectedly.
- Application cannot start after installation.

## Troubleshooting
1. Confirm the software is approved by the organisation.
2. Check the operating-system requirements.
3. Make sure enough disk space is available.
4. Restart the computer and retry.
5. Run the approved installer with the permissions required by the organisation.
6. Check the application's official error message or installation log.
7. Avoid downloading installers from untrusted websites.

## Escalation
Escalate when administrator approval, licensing, or enterprise deployment is required.
