# Password Reset

## Symptoms
- User cannot sign in.
- Password is rejected.
- User forgot their password.

## Troubleshooting
1. Confirm the username/account is correct.
2. Check keyboard layout and Caps Lock.
3. Use the organisation's official password-reset workflow.
4. Complete identity verification if required.
5. Choose a new password that meets the organisation's policy.
6. Sign in again after the reset.

## Security
Never ask users to send passwords in chat.
