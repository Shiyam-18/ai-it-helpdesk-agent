# Wi-Fi Connected but No Internet

## Symptoms
- Wi-Fi icon shows connected.
- Websites do not open.
- Some apps report no internet.

## Possible Causes
- Router or ISP issue.
- DNS resolution problem.
- Incorrect IP configuration.
- Temporary network adapter problem.

## Troubleshooting
1. Check whether another device can access the internet through the same Wi-Fi.
2. Disconnect from Wi-Fi and reconnect.
3. Restart the router if you control it.
4. On Windows, open Command Prompt and run `ipconfig /flushdns`.
5. Run `ipconfig /release` followed by `ipconfig /renew`.
6. Restart the computer.
7. If other devices also fail, contact the network administrator or ISP.

## Escalation
Create a support ticket if the standard steps fail.
